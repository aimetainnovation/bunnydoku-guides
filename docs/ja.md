# Bunnydoku ルール早見表と攻略ガイド

Bunnydoku は、色分けされたエリアの条件を論理的に整理してウサギを見つけるパズルゲームです。推測に頼らず、行・列・エリアと隣接禁止のルールから解き進めます。

## 基本ルール

### Classic Mode

各行、各列、各色エリアにウサギを**ちょうど1匹**置きます。ウサギ同士は縦・横・斜めのいずれでも隣り合えません。

### Double Bunny Mode

Double Bunny は**1人で遊ぶ高難度の論理モード**です。各行、各列、各色エリアにウサギを**ちょうど2匹**置きます。ウサギ同士が斜めを含めて隣り合えないルールも同じです。対戦モードではありません。

## 基本操作

- セルを素早く2回タップしてウサギを置きます。
- 1回タップすると `X` を付け、もう一度タップすると解除できます。
- 押したままドラッグすると、複数セルに `X` をまとめて付けたり消したりできます。
- ゲームのミス判定で付いた誤りマークは、手動では消せません。

デイリーチャレンジは通常レベル20で解放され、端末のローカル日付に基づきます。クリア後は「ウサギのヒント」1個または「電球ヒント」1個を選べます。連続記録はローカル日付で続けてプレイした日数を数え、7日目の基本ギフトはウサギのヒント3個と電球ヒント3個です。
