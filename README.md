# Bunnydoku — Official Rules & Guides

Bunnydoku is a colorful region logic puzzle for iOS and Android. Solve each board through deduction: place every bunny using the row, column, region, and non-touching rules without guessing. Its one-per-group logic is in the same family as Star Battle and other region-based logic puzzles. Core puzzle play is available offline.

For help with controls, rewards, or purchases, see the [player FAQ](FAQ.md).

## Quick rules

### Classic Mode

Place **exactly one bunny** in every row, every column, and every colored region. Any two bunnies must not touch, including diagonally.

### Double Bunny Mode

Double Bunny is a **single-player, higher-difficulty logic mode**. Place **exactly two bunnies** in every row, every column, and every colored region. Bunnies still cannot touch, including diagonally.

### Basic controls

- Quickly tap a cell twice to place a bunny.
- Tap once to add or remove an `X` mark.
- Press and drag to mark or clear `X` marks across multiple cells.
- An incorrect mark created by the game's mistake handling cannot be manually cleared.

### 5×5 rule example

In this completed Classic example, letters A through E identify five connected regions. A star (`*`) marks a bunny, and a dot (`.`) marks an empty cell.

```text
       C1   C2   C3   C4   C5
R1     A*   A.   A.   A.   B.
R2     A.   B.   B*   B.   B.
R3     A.   B.   C.   C.   C*
R4     A.   D*   D.   C.   C.
R5     D.   D.   E.   E*   E.
```

Each row, column, and region contains one bunny, and none touch. For a first deduction on the empty board, notice that all of region E lies in row 5. Row 5's bunny must be in E, so you can mark the two D cells in that row with `X`.
